# Smart Notice Board

A web-based notice board for sharing announcements with students.

**Live demo:** [insanehunter47.pythonanywhere.com](https://insanehunter47.pythonanywhere.com)

## Features

- View notices on a web page
- Admin and student login pages
- Create and edit notices
- Manage student accounts
- Mobile-friendly notice view
- Support for images, videos, PDFs, and QR codes

## Built with

- Python
- Flask
- HTML and CSS
- JavaScript

## Project structure

- `app.py` — application entry point
- `add_students.py` — student setup utility
- `templates/` — web page templates
- `static/` — styles and browser assets
